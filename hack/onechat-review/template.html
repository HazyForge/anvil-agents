One Chat Review

YOU → MANAGER

One conversation

You only talk to the manager. For each message it reads every session's recent history, then answers, reads status, continues a session, starts one, or asks you.

LOCAL

Harness binaries here

Claude Code and Codex run directly on this machine in a project folder. Claude may edit only that folder; Codex runs in a read-only or workspace sandbox.

CLOUD

Anvil Agents API

Cloud sessions are chats on agents.anvil.hazyforge.io, run by the cluster on its own keys. The manager creates threads, sends messages and waits for real replies through the API.

What you're approving

  1. Routing: the manager picks the session that already holds the work, and starts new work in the setup whose tags fit, local or cloud.
  2. Handoff: sessions share no memory, so the manager writes self-contained messages and carries one session's result into another.
  3. Restraint: it answers from transcripts when it can, asks only when the target or the authority is unclear, and never publishes or spends on its own.
  4. Evidence: every reply below is the harness's real output, with its receipt and cost. Nothing here is scripted.
